Question 1 — Punctuation: Sentence BoundaryHARD
The subterranean mycelial networks linking old-growth Douglas firs redistribute carbon and warning chemicals across the forest_______ they function less like isolated organisms than like a single cooperative system.
Which choice completes the text so that it conforms to the conventions of Standard English?
A) forest, they
B) forest; they
C) forest they
D) forest, and, they
B — Punctuation: Sentence Boundary. Two ICs, no conjunction -> [IC; IC]. A is a comma splice, C a run-on, D adds an illegal second comma.
Question 2 — Punctuation: Colon ListHARD
Before calibrating the cryogenic sensors for the Antarctic borehole mission, the engineering crew assembled four custom instruments_______ a distributed acoustic array, a laser fluorometer, a magnetotelluric probe, and a sterile coring module.
Which choice completes the text so that it conforms to the conventions of Standard English?
A) instruments;
B) instruments,
C) instruments:
D) instruments—and
C — Punctuation: Colon List. IC before blank introduces a list -> colon. Semicolon needs an IC after; a comma cannot launch a list; dash+and is unidiomatic.
Question 3 — Punctuation: Singular PossessiveHARD

Which choice completes the text so that it conforms to the conventions of Standard English?
A) curators
B) curators's
C) curator's
D) curators'
C — Punctuation: Singular Possessive. Singular 'chief curator' -> curator's. B never valid for regular nouns; D is plural.
Question 4 — Punctuation: Dependent + IndependentHARD

A) projected;
B) projected
C) projected:
D) projected,
D — Punctuation: Dependent + Independent. 'Even though...' is a DC -> [DC, IC]. Semicolon/colon cannot follow a dependent clause.
Question 5 — Punctuation: FANBOYSHARD

A) aquifer, yet
B) aquifer
C) aquifer; yet
D) aquifer,
A — Punctuation: FANBOYS. Two ICs joined by FANBOYS 'yet' -> [IC, yet IC]. B is a run-on, C is semicolon+FANBOYS (never on SAT), D is a comma splice.

B) its'

Question 7 — Punctuation: Serial CommaHARD

B) ,

Question 10 — Punctuation: Conjunctive AdverbHARD

Question 18 — Punctuation: Colon ResultVERY HARD

Question 19 — Punctuation: That vs. WhichVERY HARD

Question 31 — Grammar: Subject-Verb AgreementHARD
The array of tide gauges deployed along the subsiding delta_______ sea-level rise at millimeter precision despite biofouling and storm damage.
Which choice completes the text so that it conforms to the conventions of Standard English?
A) monitor
B) have monitored
C) monitors
D) are monitoring
C — Grammar: Subject-Verb Agreement. Subject is singular 'array' (PP 'of gauges' is a distractor). Singular present -> monitors. B/D are plural.
Question 32 — Grammar: Neither/Nor AgreementHARD
Neither the field coordinators nor the principal investigator_______ satisfied with the chain-of-custody documentation for the ice cores.
Which choice completes the text so that it conforms to the conventions of Standard English?
A) were
B) are
C) was
D) be
C — Grammar: Neither/Nor Agreement. With neither/nor, verb agrees with nearest subject ('investigator' singular) -> was. Proximity rule.
Question 33 — Grammar: Number / A NumberHARD
The number of peer-reviewed retractions linked to image duplication_______ sharply since journals adopted automated screening.
Which choice completes the text so that it conforms to the conventions of Standard English?
A) have risen
B) has risen
C) rise
D) are rising
B — Grammar: Number / A Number. 'The number' = singular -> has risen. ('A number' would take plural.) Don't be fooled by plural 'retractions'.
Question 34 — Grammar: Tense ConsistencyHARD

Which choice completes the text so that it conforms to the conventions of Standard English?
A) has compiled
B) had compiled
C) compiles
D) will compile
B — Grammar: Tense Consistency. Past-perfect needed: action completed BEFORE another past event ('convened'). 'Has' is present-perfect; C/D misplace time.
Question 35 — Grammar: Future PerfectHARD

A) will have calibrated
B) calibrated
C) have calibrated
D) had calibrated
A — Grammar: Future Perfect. Deadline in the future ('by the next equinox') completed before then -> future perfect 'will have calibrated'.

Question 38 — Grammar: Who vs. WhichHARD

B) whom
C) who
D) whose
C — Grammar: Who vs. Which. People -> 'who' as subject. 'Which' is for things; 'whom' is object case; 'whose' is possessive.
Question 39 — Grammar: Dangling ModifierHARD

Question 42 — Grammar: Illogical ComparisonVERY HARD

Question 43 — Grammar: TransitionVERY HARD

A) Consequently,
B) Moreover,
C) However,
D) For example,
C — Grammar: Transition. Second sentence contrasts/counters the success -> 'However'. Consequently = cause-effect; Moreover = continuation; For example = instance.
Question 44 — Grammar: Transition (Cause)VERY HARD

B) for instance,
C) nevertheless,
D) consequently,
D — Grammar: Transition (Cause). Rationing is the RESULT of falling recharge -> 'consequently'. 'Nevertheless/in contrast' signal opposition; 'for instance' signals example.
Question 45 — Grammar: One of + That (Agreement)VERY HARD

B — Grammar: One of + That (Agreement). 'That' refers to plural 'reviews' (one of the reviews that confirm...), not singular 'one' -> plural 'confirm'. Classic SAT trap.
Question 46 — Grammar: Conditional / SubjunctiveVERY HARD

Question 52 — Grammar: Tense + Voice in SequenceEXTREME

Question 59 — Grammar: Affect / Effect + PrecisionEXTREME
Reviewers warned that the dam's altered sediment regime would_______ downstream spawning beds and, in turn, produce cascading ecological _______.
Which choice completes the text so that it conforms to the conventions of Standard English?
A) effect / affects
B) affect / effects
C) effect / effects
D) affect / affects
B — Grammar: Affect / Effect + Precision. Verb = affect (to influence); noun = effects (results). 'Effect' as verb = to bring about (wrong here); 'affects' as noun is a verb form.
Question 60 — Grammar: Concision + Redundancy HybridEXTREME
The committee's final consensus was that the two plans, both alike in their shared uniformity, should be merged.
Which choice completes the text so that it conforms to the conventions of Standard English?
A) both alike in their shared uniformity,
B) identical,
C) alike and uniform and similar,
D) sharing the same uniform likeness together,
B — Grammar: Concision + Redundancy Hybrid. All options except B stack synonyms ('both alike,' 'shared uniformity'). SAT concision: 'identical' carries the full meaning alone.
